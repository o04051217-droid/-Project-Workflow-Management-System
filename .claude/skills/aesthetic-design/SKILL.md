# 美感設計（總 Skill）

本 Skill 是所有視覺設計手法的總入口：共用規則＋選擇表＋各模組精簡規格。完整拆解、座標、範例與產生程式放在本 Skill 資料夾的 `design/approaches/`（先讀 `README.md`）；底圖產生器與簡報產生程式放在 `design/`。

## 一、適用範圍與分工（強制）

| 頁型 | 負責 | 規定 |
|---|---|---|
| 封面 | 本 Skill | 必須從模組中選一種構圖 |
| 章節分隔頁 | 本 Skill | 必須從模組中選；全份交替 2 種為上限 |
| 結尾頁 | 本 Skill | 放名片聯絡資訊 |
| 對照頁、議程頁 | 本 Skill（選用） | 對照用 A3 左右居中；議程、三大重點用 A7 重複 |
| 內文頁（文字解說、卡片、表格、時程、數字） | intellicore-consulting-deck | 排版依智本品牌規則；**字型仍依本 Skill 第二節**；表格須有格線；不用破壞手法 |
| 海報、IG 宣傳圖 | 本 Skill | 4:5 或 9:16，同樣依選擇表 |

優先順序：使用者本次指示 → 使用者提供的範本 → 本 Skill（封面、章節、結尾、全份字型）／智本品牌規則（內文排版）。

## 二、共用規則

### 2.1 四個原則
1. **一個主角**：每頁一個主體（重複構圖例外），背景大量留白或單一素色。
2. **文字依附主體**：文字貼著主體邊緣、中軸、縫隙、視線方向或破口擺放。
3. **字級三層**：大標、中副標、極小英文與說明，不出現第四種大小。
4. **一個收尾元素**：一條細線、一個細框或一道破口，一頁只用一個。

### 2.2 字型系統（全份統一，含內文頁）

| 角色 | PowerPoint 字型名稱 | 用在 | 字級（16:9 寬版） |
|---|---|---|---|
| 顯示 | Noto Serif TC Black（＝思源宋體 Heavy） | 封面、章節、結尾標題；內文頁標題；主角數字；單字 | 54pt／內文頁標題 32pt／數字 66pt |
| 副標 | Noto Serif TC SemiBold | 副標、卡片標題、時間軸節點 | 16～22pt，字距加寬 |
| 內文 | Noto Sans TC（強調用粗體） | 內文、條列、表格、註記、頁尾 | 20／16／14／12pt |
| 英文 | Georgia，全大寫，字距加寬 | 英文副標、CHAPTER 章號 | 11～12pt |

- Black、SemiBold 是獨立字型名稱，不要再勾粗體。文字語言設為 zh-TW。
- 網頁版用 Google Fonts：Noto Serif TC（600;900）、Noto Sans TC（400;700）、Georgia。
- 電腦需安裝 Noto Serif TC、Noto Sans TC 靜態字型；匯出 PDF 確認字型內嵌。
- LibreOffice 預覽時部分標題字序會錯亂，屬預覽工具問題，以 PowerPoint 或瀏覽器為準。

### 2.3 色彩與素材
- 全份最多 5 色：墨色、白、一個主色（取自主體照片或客戶品牌色）、暖灰、淡卡片色。
- 主體照片長邊至少 2000px（切片主體至少 1000px）；白底照片先去背；低解析度時交付時說明。
- 不用他人品牌商品照做成像官方廣告的版面；人像要補日期、帳號、攝影署名。

### 2.4 簡報技術
- 疊壓、紋理、破壞版面的照片設為「投影片背景圖片」（先裁成 16:9），框與文字才會疊在照片上。
- 中文直排用 upright；英文直排在簡報用 eaVert（橫躺閱讀），框寬至少 0.45in。
- 文字一律用可編輯文字框，不把字燒進圖片。
- 母片與產生程式：`design/鑽全_產品碳足跡建置說明_破壞版_build.js`（含模組 A 與 B 全部母片；`PREVIEW=1` 產生預覽用版本）。完整 v2 母片保留在 claude.ai 專案「SKILL升級中」。

## 三、選擇表

| 情境 | 主模組 | 建議版面 |
|---|---|---|
| 說明會、教育訓練、輔導計畫（穩重） | A 單一主體構圖 | 封面 A6 疊壓或 A1 上中下；章節 A2／A5 交替；結尾 A8 |
| 成果報告、結案 | A 單一主體構圖 | 封面 A6 疊壓；結尾 A8 |
| 提案、比稿、要強烈記憶點 | B 破壞 | 封面 B 撕紙破口＋出框；章節 B 切片／紙條／碎字 |
| 活動海報、IG 宣傳 | A 或 B | 人像用 A1／A2／A5；促銷用 B |
| 只有一張低解析照片 | A 小尺寸版面或 B 碎字 | 不放大主體；改用字做主角 |

- 一份簡報只選一個主模組，最多再借用另一模組的一種手法做點綴（例如穩重版只把封面換成破壞）。
- 一份簡報的封面、章節、結尾合計使用 2～4 種構圖。

## 四、模組精簡規格

### 模組 A｜單一主體八種構圖（詳：`design/approaches/01_單一主體構圖.md`）

| # | 構圖 | 做法 | 適用 |
|---|---|---|---|
| A1 | 上中下 | 大標在上、主體居中、副標＋細線在下 | 說明會封面、自我介紹 |
| A2 | 上下 | 主體放大超出下緣，文字在上方留白 | 章節頁、主視覺 |
| A3 | 左右居中 | 主體分列左右、視線朝內，直排大標在中軸 | 對照頁 |
| A4 | 對角 | 主體在右上、左下；文字在另兩角 | 活潑封面、季節主題 |
| A5 | 裁切居中 | 主體切一半貼邊，直排文字貼邊，可用「／」分字 | 引言、章節、氣質人像 |
| A6 | 疊壓 | 照片鋪滿，文字壓上，細框只框部分畫面 | 成果報告、結案封面 |
| A7 | 重複 | 主體複製 3～5 個，每個放一個字 | 議程、三大重點 |
| A8 | 從主體找答案 | 拉近取紋理或照片本身留白，文字順紋理擺 | 結語、願景 |

禁忌：主體太小留白空洞（改 A2／A5）；每頁換構圖（限 2～4 種）；為了好看加漸層、陰影、圓角卡片。

### 模組 B｜破壞（詳：`design/approaches/02_破壞.md`）

理念：打破完整，用破口製造焦點和新平面；破壞不等於看不懂，資訊必須完整。

| 手法 | 做法 | 適用 |
|---|---|---|
| B1 產品切片 | 主體切 4～5 段、留縫、交錯微旋轉；每段可標一個階段 | 生命週期、組成、流程 |
| B2 撕紙破口 | 品牌色紙面撕出破口（占 40%～55%），破口露照片，米白纖維邊＋內陰影 | 封面、章節頁 |
| B3 出框 | 主體部分穿出破口壓在紙面，加投影 | 搭配 B2 |
| B4 撕紙平面 | 照片上撕一條素色紙條，文字放紙條上 | 照片雜亂、文字難讀 |
| B5 破碎字 | 大字沿裂線切塊、微位移、碎片 ≤4%，仍認得出 | 沒有好照片時 |

- 底圖用 `design/破壞式底圖產生器_destroy.py` 產生（換照片路徑與品牌色）。
- 禁忌：規則鋸齒破口；破壞到認不出；內文頁也破壞；撕紙邊用純白；白底撕白洞。

## 五、品質檢查

- [ ] 封面、章節、結尾都有對應模組與版面名稱，全份 2～4 種構圖
- [ ] 字型只有第二節的四種角色，沒有混入其他宋體或黑體
- [ ] 一頁一個主體、一個收尾元素；字級三層
- [ ] 文字沒有壓到臉、商標或主體重點；背景雜亂處已加紙條或半透明底
- [ ] 主體清晰不模糊；去背無殘邊
- [ ] 破壞手法下，產品與字仍認得出、資訊完整
- [ ] 文字框貼合內容，無大片空框或溢出；表格有格線
- [ ] 照片設為背景的頁面，框與文字確實在照片上方

## 六、新增模組

收到新的設計影片或範例時：
1. 拆解（逐格看完）→ 寫進 `design/approaches/README.md` 候選區。
2. 試做 3～5 頁並通過第五節檢查。
3. 寫 `design/approaches/0N_模組名.md`（README 有模板）。
4. 在本 Skill 的選擇表加一列、第四節加一個 20～30 行內的模組。

收錄門檻：可通用到顧問簡報、已實際驗證、與既有模組不重複（重複就併入既有模組）。未驗證的不得寫進本 Skill。
