# 模組 A｜單一主體八種構圖

來源：nanxi_design〈一顆荔枝的高級感排版〉拆解，並以兩個實作範例驗證。
- 範例 A｜荔枝排版實驗（物件主體、16:9 簡報）：https://claude.ai/artifact/JdRZ14JSVNETPFr3r7HdTr
- 範例 B｜Angela 出道宣傳排版（人像主體、4:5 IG）：https://claude.ai/artifact/Bmr9hJq1jjL8hKz2iTZ3xg
- 原理頁｜一個主體的八種排版（葉子＋碳足跡）：https://claude.ai/artifact/NvfmUCHL2PHaAJpm325S3d

## 一、頁型對應（原始版本）

只要產出簡報、海報、社群圖、成果報告封面，就要套用本規範：

| 頁型 | 規定 |
|---|---|
| 封面 | 必須使用八種構圖之一 |
| 章節分隔頁 | 必須使用八種構圖之一，全份簡報統一或交替使用 2～3 種 |
| 雙概念對照頁（現況／目標、改善前後） | 優先用「左右居中」 |
| 議程、三大重點、三階段 | 優先用「重複」 |
| 結語、願景頁 | 優先用「從主體找答案」或「疊壓」 |
| 一般內容頁（表格、圖表、條文） | 不強制套用；但須遵守「留白、字級對比、細線」原則，表格仍須有格線 |

優先順序：使用者本次指示 → 使用者提供的範本／智本品牌規則 → 本規範。

## 二、四個共同原則

1. **只放一個主體**：一張圖、一個主角，背景大量留白，不加裝飾框與色塊。
2. **文字依附主體**：文字貼著主體的邊緣、中軸、縫隙或人物視線方向擺放，不另外排一塊。
3. **字級極端對比**：大標粗重（約畫面寬 7%～15%），副標中等（約 2%～3.5%），英文與說明極小（約 1%～2.6%）；不出現第四種大小。
4. **一條細線收尾**：標題下方一條 1px 細線，或一個只框住部分畫面的細框。

## 三、八種構圖規格

座標以畫面寬度為 100 計（16:9 高 56.25；4:5 高 125）。

| # | 構圖 | 做法 | 適用 | 關鍵參數 |
|---|---|---|---|---|
| 1 | 上中下 | 大標在上、主體居中、副標＋細線在下，全部置中 | 教育訓練、說明會封面、第一篇自我介紹 | 主體寬約 16～26（16:9）／54（4:5） |
| 2 | 上下 | 主體放大超出下緣，只露上半；文字在上方留白 | 章節頁、主視覺 | 主體寬 45～100，頂端從 20～27 開始 |
| 3 | 左右居中 | 主體分列左右（視線朝內），直排大標放中軸 | 對照頁、兩種風格 | 兩側主體各寬 27～34 |
| 4 | 對角 | 主體在右上、左下；文字在左上、右下 | 活潑封面、季節或活動主題 | 兩主體大小差約 1.5 倍；文字不得壓到主體 |
| 5 | 裁切居中 | 主體切一半貼邊，直排文字貼著主體邊緣或視線前方，可用「／」分隔字 | 引言頁、觀念頁、氣質型人像 | 主體約占畫面 50%～55% |
| 6 | 疊壓 | 主體放大鋪滿，文字壓在主體上，加一個只框部分畫面的細框 | 成果報告、結案封面 | 背景亮時字用深色，背景雜亂時框內加半透明白底 |
| 7 | 重複 | 同一主體複製 3～5 個（人像改用同尺寸裁切），每個只放一個字 | 議程、三大重點、輪播首張 | 主體等距、等大；字放在主體上同一位置 |
| 8 | 從主體找答案 | 拉到極近或取照片本身的留白（天空、果肉、葉脈），文字順著主體紋理擺放 | 結語、願景、情緒型主視覺 | 需高解析度特寫；文字放在平滑或過曝區 |

## 四、執行步驟

1. **確認主體**：從客戶產品照、設備、原料、人像或代表性物件中選一個；沒有照片時，先問使用者，不用素材網站圖片冒充客戶產品。
2. **準備素材**：白底照片先去背；長邊至少 2000 px，放大裁切的版型（2、5、8）尤其需要。低解析度時須在交付時說明。
3. **選構圖**：依第一節的頁型對應表挑選；一份簡報封面、章節、結語合計使用 2～4 種，不要八種全用。
4. **取色**：文字色從主體照片取（例：荔枝的深紅、毛衣的深藍、夕陽的暖棕），中性色帶一點主色色相，不用純灰。
5. **排字**：大標用粗襯線（如 Noto Serif TC 900），英文用細襯線斜體或小型大寫；中文直排使用 upright，英文直排使用 mixed。
6. **加細線或細框**：一頁只加一個。
7. **品質檢查**（見第五節）後交付。

## 五、品質檢查

- [ ] 一頁只有一個主體（重複構圖例外）
- [ ] 文字沒有壓到臉、商標或主體重點部位
- [ ] 字級只有大、中、小三層
- [ ] 背景雜亂處的文字已加深色或半透明底，手機上看得清楚
- [ ] 主體放大後不模糊；模糊時已告知使用者換圖
- [ ] 去背邊緣沒有殘留背景或相鄰物件
- [ ] 文字框大小貼合內容，沒有大片空框或溢出
- [ ] 表格（若有）保留格線
- [ ] 沒有使用他人品牌商品圖做成像官方廣告的版面
- [ ] 人像作品：確認已補上日期、帳號或聯絡方式；需要時加攝影署名

## 六、常見錯誤與處理

| 錯誤 | 處理 |
|---|---|
| 直排英文長度超出，壓到下方主體 | 縮小字級或縮短主體高度，保持至少 4 單位間距 |
| 白字壓在白色背景（櫻花、天空） | 改用從照片取的深色字，或加半透明白底 |
| 主體太小、留白顯得空 | 換「上下」或「裁切居中」，讓主體放大裁切 |
| 每頁都套不同構圖，風格亂 | 全份簡報限 2～4 種，章節頁統一同一種 |
| 為了好看加漸層、陰影、圓角卡片 | 刪除；本規範只靠留白、字級與細線 |
| 用他人品牌商品照當主體 | 改用客戶自有產品或通用物件 |
