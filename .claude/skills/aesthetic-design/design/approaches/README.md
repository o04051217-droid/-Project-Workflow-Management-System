## 收錄門檻

新設計要同時符合三項，才從候選區升為模組並寫進 Skill：

1. **可通用**：能套用到顧問簡報（封面、章節頁、結尾頁、海報），不是只適合食品或時尚。
2. **已驗證**：至少實際做過一份（簡報或宣傳圖），並通過品質檢查。
3. **不重複**：與既有模組的手法不同；重複的併入既有模組，作為新增手法。

## 新增模組流程

1. 拆解影片：逐格看完，寫出「理念一句話＋手法清單＋禁忌」，放進候選區。
2. 試做：用一個真實或示範主題做 3～5 頁。
3. 檢查：依 Skill 的共用品質檢查。
4. 寫文件：新增 `0N_模組名.md`（用下方模板）。
5. 更新 Skill：在選擇表與模組區各加一段（20～30 行內），透過 Skill 提案卡片儲存。

## 模組文件模板

```
# 模組 X｜名稱
來源：
理念一句話：
## 手法
| 手法 | 做法 | 適用 | 關鍵參數 |
## 版面名稱與座標
## 禁忌與常見錯誤
## 驗證實例（檔案、連結、產生程式）
```
