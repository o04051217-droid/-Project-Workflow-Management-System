# 顧問服務報價試算

## 使用時機
- 新客戶詢價、需要報價單或專案說明附報價頁時。
- 多系統整合案、多場域或多產品案要估價時。

## 必要輸入
1. 服務項目（可多項）。
2. 系統複雜度、場域數、產品數、時程急迫性、是否策略客戶、是否跨系統整合。
3. 是否含查驗／驗證費（第三方費用分開列示）。
4. 付款期數與條件。

## 基準資料（來源：使用者的「ISO 管理系統服務費用權重報價表_自動試算」，使用前確認是否已更新）
| 服務 | 基準起價（萬元） | 建議區間（萬元） |
|---|---|---|
| ISO 9001 | 10 | 10–18 |
| ISO 14001 | 20 | 20–35 |
| ISO 45001 | 20 | 20–35 |
| ISO 50001 | 20 | 22–40 |
| ISO 27001 | 20 | 22–45 |
| ISO 14064 單場域 | 15 | 15–28 |
| ISO 14067 單產品 | 15 | 15–30 |
| 永續報告書 | 25 | 25–60 |
| ISO 22000、ISO 13485、HACCP | 20 | 權重未定 |
| ISO 46001 | 25 | 權重未定 |
IATF 16949、RBA、SA8000、AS9100、ISO 22716、PSI、GRS 尚無基準，需使用者提供。

評估因子：複雜度 簡單 0.9／一般 1.0／複雜 1.2／高複雜 1.4；場域每增 1 個 +0.1；產品每增 1 個 +0.08；急件 1.1–1.3；策略客戶 0.9；跨系統 雙系統 1.15／三系統 1.25。

## 執行步驟
1. 帶入基準價，依因子相乘得試算價，給出建議區間。
2. 若低於建議最低價，必須寫明原因（既有系統維護、文件成熟、同集團導入、競爭案、年度框架案等）。
3. 第三方查驗費用、政府補助款與顧問費分開列示。
4. 產出報價單草稿：工作項目、數量、單價、優惠價、未稅合計、付款期數與條件、有效期限。
5. 同步產出專案總表欄位：報價單號、客戶、統編、計畫總額（含稅）、各期請款金額與預計日期。

## 品質檢查
- 金額單位一致（元或萬元），含稅／未稅標示清楚。
- 合計公式正確，期數金額加總等於總額。
- 沒有權重的服務項目不自行推估，列為待確認。

## 輸出規格
- 報價試算說明（因子、係數、結果）。
- 報價單草稿（Word 或 Excel）。
- 專案總表一列資料。

## 常見錯誤與處理
- 把第三方查驗費混入顧問費 → 分列。
- 使用過期基準價 → 先確認試算表最新修改日期。
- 對外寄出報價前，需使用者確認。
