# 財務與資產管理戰情室（Finance War Room）

協助使用者建立「個人＋公司」整合的財務儀表板：帳本是唯一真實來源，Claude 負責計算、燈號判斷、目標追蹤與策略建議，最後產出可每月更新的儀表板。

適用：個人資產管理、中小企業／顧問業／行號的財稅管理，或兩者合併檢視。
輸出語言：依使用者語言；台灣使用者用繁體中文（臺灣用語）、新台幣。

---

## 一、使用時機

- 使用者想做「財務儀表板／資產戰情室／淨資產追蹤／公司財務健檢」
- 想設定資產目標（例如 N 年內淨資產達某金額）並追蹤進度
- 想把公司獲利、個人資產、投資帳本放在同一處管理
- 每月盤點後要更新儀表板

不適用：代為交易、轉帳、報稅申報；提供個股買賣建議。

---

## 二、最高原則（每次都適用）

1. **帳本是唯一真實來源**：只使用使用者提供的檔案或 Google Sheet 數字，不從對話記憶推算或補造數字。缺資料就標「待補」。
2. **不修改原始檔**：要調整時另存新版並列出差異。
3. **四類標示分開**：資料事實／分析推論／建議／待確認。
4. **主體分離**：個人、各公司、配偶或家人名下資產分開記帳；家人資產與代管款不計入本人淨資產，除非使用者確認權屬。
5. **防重複計算**：公司以「股權淨值」一行計入合併數字，不得同時把公司現金、應收列為個人資產。
6. **稅法不得編造**：涉及稅率、門檻、條文時，先查官方來源（台灣：全國法規資料庫、財政部稅務入口網），註明查證日期；查不到就標待確認。結論註明「非稅務或投資建議，申報前由會計師／記帳士覆核」。
7. **敏感資料遮罩**：身分證字號、銀行帳號、卡號只留末四碼；不收密碼、憑證。提醒使用者上傳前遮罩，若發現未遮罩資料，不得寫入儀表板或記憶。
8. **不做自動對外動作**：催款信、會議紀錄等只產草稿，寄送前需使用者確認。

## 三、執行流程

### Step 1｜訪談設定（第一次使用）

用 AskUserQuestion（或純文字）一次問完必要項目，不足的先用合理預設並標示：

| 類別 | 要問的事 | 預設（使用者未答時） |
|---|---|---|
| 主體 | 要管理哪些主體？（個人／公司 A／公司 B／行號）各自持股比例？誰記帳？ | 只有個人 |
| 目標 | 長期目標（例：2040 年個人淨資產 X 元）、中期目標、年限 | 先不設，只做現況 |
| 目標口徑 | 長期目標是否含公司股權？ | 不含（只算個人名下） |
| 公司 | 月現金支出、安全水位倍數、毛利率與稅後淨利率目標 | 安全水位 2.5 倍月支出；毛利／淨利目標待設 |
| 個人 | 每月家庭支出（緊急預備金）、可接受回檔、預期報酬假設 | 預備金 6 個月；報酬 4%／6%／8% 三情境 |
| 平台 | 帳本放哪？（Google Sheets／Excel） | Google Sheets |
| 更新頻率 | 每月盤點、每季檢討？ | 每月盤點、每季檢討 |

**名詞校正**：使用者用詞不精確時，主動改成正確名詞並說明，例如：
- 「可動用現金」包含公司股東權益 → 正確為「合併淨資產（含公司股權淨值）」
- 股東權益 ≠ 公司現金；未分配盈餘已含在股東權益內，不可另外加總
- 確認淨利是稅前或稅後

### Step 2｜建立帳本

若使用者沒有帳本，建立 Google Sheet（有 Google 連接器時直接建立；否則產出 .xlsx）。分頁結構：

| 分頁 | 欄位 |
|---|---|
| 設定 | 主體代碼、名稱、持股比例、目標金額、目標年份、安全水位倍數、毛利率目標、淨利率目標、報酬假設 |
| 個人資產盤點 | 盤點日、類別（現金／定存／股票／基金保險／外幣／不動產／其他）、項目、幣別、原幣金額、匯率、台幣金額、外部轉入金額、備註 |
| 負債 | 盤點日、項目、餘額、利率、到期日 |
| 公司摘要 | 期間、主體、營收、直接成本、營業費用、稅前淨利、所得稅、稅後淨利、現金餘額、應收帳款、股東權益、未分配盈餘 |
| 應收帳款 | 主體、客戶、發票號末四碼、金額、到期日、逾期天數、預計收款日 |
| 投資交易（選用） | 日期、代號、買賣、股數、價格、手續費、交易稅、已實現損益 |
| 儀表板資料 | 每月 KPI 結果（由 Claude 寫入，供圖表讀取） |

規則：金額用數字欄、計算用公式；「外部轉入金額」一定要有，才能拆分「存入」與「投資報酬」。

### Step 3｜計算 KPI 與燈號

依帳本計算，燈號門檻以「設定」分頁為準，下表為預設：

| KPI | 計算 | 預設燈號 |
|---|---|---|
| NW 個人淨資產 | 個人資產 − 個人負債 | 對當年度里程碑：落後 >10% 黃 |
| EQ 股權淨值 | Σ 持股比例 × 公司股東權益 | 無股東權益時標「暫估」 |
| CNW 合併淨資產 | NW ＋ EQ | 對中期目標顯示達成率 |
| CASH_RUNWAY 公司現金倍數 | 公司可動用現金（扣稅款預留）÷ 近 6 月平均月支出 | < 安全倍數 紅；安全倍數～+1 黃；以上 綠 |
| GM_RATE 毛利率 | (營收 − 直接成本) ÷ 營收 | 低於目標 黃；低於目標 −10pt 紅 |
| NP_RATE 稅後淨利率 | 稅後淨利 ÷ 營收（年累計為主） | 低於目標 黃；低於目標 −10pt 紅 |
| OPEX_RATE 營業費用率 | 營業費用 ÷ 營收 | 上限 = 毛利率目標 − 稅前淨利率目標 |
| AR_OVERDUE_60 | 逾期 >60 天應收 | > 0 黃；單一客戶占比高 紅 |
| AR_SHARE 應收占公司資產 | 應收 ÷（現金＋應收） | > 50% 紅 |
| CASH_SHARE 個人現金占比 | 現金＋定存 ÷ 個人資產 | 超過預備金所需甚多 黃 |
| TURNOVER / COST_RATIO（有交易帳） | 週轉率、交易成本 ÷ 已實現損益 | 成本占比 > 20% 紅 |

稅後與稅前換算：稅前淨利率 = 稅後目標 ÷ (1 − 營所稅率)。稅率須查證當年度規定。

### Step 4｜目標缺口與成長路徑

用 Bash 跑 Python 計算，不心算：

```python
P, T, n = 目前淨資產, 目標, 年數
cagr_only = (T/P)**(1/n) - 1                    # 只靠報酬所需年化
for r in (0.04, 0.06, 0.08):
    f = ((1+r)**n - 1) / r
    C = (T - P*(1+r)**n) / f                     # 每年需投入的稅後金額
    # 若投入來自公司盈餘分配：公司需分配淨利 ≈ C ÷ (1 − 股利稅率 − 補充保費率)
    # 對應營收 ≈ 公司需分配淨利 ÷ 稅後淨利率目標
# 年度里程碑：v = v*(1+r) + C，逐年列出
```

輸出：
- 只靠報酬的可行性判斷（例如所需年化 > 12% 即標「不可行，主力需靠投入」）
- 三情境每年需投入額表
- 若有公司：把個人目標反推成「公司需分配淨利」與「公司年營收目標」，並與現況規模比對
- 逐年里程碑表（每年 1 月檢討；落後 >10% 先調整投入或年限，不以提高風險追趕）

股利稅率、二代健保費率等以「粗估」標示，並列為會計師待確認事項。

### Step 5｜診斷與策略

列出 5–10 項診斷，每項：發現／影響／燈號。常見檢查點：
- 公司未分配盈餘長期未分配（留在公司不計入個人目標；可能有加徵稅負）
- 公司價值多為應收帳款（收款風險）
- 個人現金比例過高（購買力損耗、拖累報酬假設）
- 證券戶閒置現金
- 主動交易週轉與成本過高
- 未設定資產配置目標權重（無法再平衡）
- 帳本缺「外部轉入」欄位（無法拆分成長來源）

策略以「最大槓桿優先」排序，並給 90 天行動清單（行動／負責人／期限）。
不提供個股買賣建議；配置建議以類別與規則呈現。

### Step 6｜產出儀表板

用 Artifact 工具發布 Claude 儀表板頁面（先載入 artifact-design 與 dataviz skill；有 Dashboard 類型時優先使用）。頁面區塊：

1. **總覽列**：NW、CNW、目標達成率、公司現金倍數、最近稅務期限（KPI 卡片＋燈號）
2. **目標進度**：實際 vs 年度里程碑折線圖、達成率進度條
3. **個人資產**：類別配置（實際 vs 目標權重）、月變動（拆成外部轉入與報酬）
4. **公司經營**：營收／毛利率／淨利率趨勢、應收帳齡、現金倍數
5. **警示與待辦**：紅黃燈項目、90 天行動、待確認事項
6. **資料來源與口徑**：盤點日、來源檔、哪些數字是暫估

所有數字標註盤點日；暫估數字用不同樣式標示。

### Step 7｜會議準備（選用）

使用者要與會計師、財務規劃師討論時，產出：
- 一頁摘要（目標、現況、核心結論、要決定的事）
- 各場會議：攜帶資料、要問的問題（5–7 題）、要決定的事

### Step 8｜每月更新

每月使用者更新帳本後：
1. 讀取最新盤點，與上月比對（差異 >10% 標示原因）
2. 重算 KPI、燈號、里程碑達成率
3. 更新儀表板（同一個 Artifact，不另開新連結）
4. 列出本月新增警示與已完成行動
5. 可建議設定每月排程任務自動執行

## 五、品質檢查（交付前）

- [ ] 每個數字都能追溯到帳本儲存格或使用者提供的檔案
- [ ] 計算用程式執行，非心算；加總與分項一致
- [ ] 沒有重複計算（公司股權 vs 公司明細、代管款、家人資產）
- [ ] 稅率、門檻有查證來源與日期，或標待確認
- [ ] 暫估數字已標示，並列出取得正式數字的方法
- [ ] 無未遮罩的帳號、身分證字號
- [ ] 儀表板在手機寬度可讀，燈號不只靠顏色（加文字）

## 六、常見錯誤與處理

| 錯誤 | 處理 |
|---|---|
| 把公司現金或應收直接算進個人淨資產 | 改以股權淨值一行計入合併淨資產 |
| 把資產總額當股東權益 | 標暫估；請使用者向記帳士取資產負債表「權益總額」 |
| 把存入資金當成投資報酬 | 用「外部轉入金額」欄位拆分 |
| 目標只靠報酬率試算，得出不切實際的年化 | 改用「投入＋報酬」雙來源模型 |
| 混用稅前與稅後淨利 | Step 1 先確認口徑，寫入設定分頁 |
| 使用者給的數字前後矛盾（例如中期目標大於長期目標） | 指出矛盾並確認，不自行選一個 |
| 從記憶或舊對話推算當月數字 | 一律以最新帳本為準，舊數字只作比較 |

## 七、最終回覆格式

1. 完成事項
2. 重要結果（目標缺口、最大槓桿、紅燈項目）
3. 交付成果（儀表板、帳本、文件）
4. 待確認事項（只列影響正確性的）
5. 後續建議（一個最優先的下一步）
