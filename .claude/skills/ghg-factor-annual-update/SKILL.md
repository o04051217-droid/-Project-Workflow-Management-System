# 溫盤係數年度更新

## 使用時機
- 能源署公告新年度電力排碳係數、環境部更新溫室氣體排放係數管理表、燃料熱值或 GWP 版本變動時。
- 新年度盤查開始前，確認各客戶清冊使用的係數版本。

## 必要輸入
1. 盤查年度與適用地區（台灣、中國各省、越南、哥倫比亞、歐盟國家等）。
2. 客戶盤查清冊（Excel）與報告書（Word）。
3. 查驗機構對係數版本的要求（若有）。

## 執行步驟
1. 查證最新官方來源，不憑記憶給數值：
   - 台灣電力：經濟部能源署年度電力排碳係數公告（記錄公告日期與年度）。
   - 燃料排放係數與熱值：環境部溫室氣體排放係數管理表最新版、事業溫室氣體排放量資訊平台公告熱值。
   - 中國：生態環境部電力二氧化碳排放因子公告；越南：DCC/MONRE 公告；歐盟國家：EEA 指標；其他國家：官方能源機構優先，第三方資料庫次之並註明。
   - GWP：IPCC AR6。
2. 更新「年度係數主檔」：係數、單位、來源全名、公告日期、適用盤查年度、前一版數值。
3. 決定各客戶採用版本：依盤查年度與查驗機構要求；未確定者標「待確認」，不自行決定。
4. 更新清冊：外購電力係數、燃料熱值（汽油、柴油、LPG、天然氣）、化糞池甲烷修正係數等；只在指定欄位範圍取代，天然氣等數值不可全表一鍵取代。
5. 更新報告書：數據表（通常約 8 張）、排放量計算公式說明章節、參考文獻章節的係數來源與版本。
6. 產出差異清單：每家客戶「項目／舊值／新值／排放量變化（tCO2e 與 %）」。

## 品質檢查
- 每個係數都有來源全名與公告日期。
- 清冊與報告書總量一致；範疇（類別）小計加總等於總量。
- 報告書文獻章節的版本字樣全部更新（例如舊版 6.0.4 字樣不得殘留）。
- 熱值取代範圍正確，未誤改其他數字。

## 輸出規格
- 更新後清冊與報告書另存新版（保留原檔，不覆寫）。
- 差異清單 Excel。
- 待確認事項清單。

## 常見錯誤與處理
- 沿用舊 SOP 數值：每次都先查最新公告。
- 公告年度與盤查年度混淆：在主檔同時記錄兩者。
- 一鍵全表取代造成誤改：限定欄位範圍並在改後比對。
