# 補助計畫經費調整規則

使用者要求：經費以公文核定為準，不自行決定補助金額。

## 規則

1. 補助款依公文明定金額固定，不因科目增減而變動。
2. 計畫總經費若多出補助款的部分，全部編列在自籌款。
3. 補助款比原申請減少時，優先降低「全新設備購置費」的補助金額，其他科目維持原補助金額；設備購置費的差額轉入自籌款。
4. 公文列的設備加碼補助（例如「全新設備購置費加碼 360 千元」）含在補助款總額內、計入總經費，不另增加總經費。（使用者指示，若公文寫法不同再確認。）
5. 採用前先用一張表列出各科目的「原補助／原自籌／新補助／新自籌／合計」，確認補助款加總等於公文金額、自籌款不低於公文規定。
6. 連動更新：封面的總經費／補助款／自籌款、經費需求總表、各科目補助比例、優先支持項目（如購置全新國產設備）。

## 修改申請書的做法

- 先彙整要變動的項目與使用者確認，確認後才動原文件。
- 修正版另存新檔，原檔不動；新增或修改的字用紅字標註。
- 使用者已刪除或不要寫出的廠商與項目，不寫進任何對外文件，也不改寫成其他說法。
